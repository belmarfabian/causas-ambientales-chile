# Conflictos y justicia ambiental en Chile

Plataforma web sobre los conflictos socioecológicos chilenos y las causas que llegan a los tribunales ambientales. Reúne en un solo lugar el universo de conflictos observados, la ficha de cada uno y los datos abiertos que sostienen el análisis.

**Plataforma:** https://belmarfabian.github.io/causas-ambientales-chile/

## Estructura

El sitio se divide en tres partes declaradas:

- **Conflictos socioecológicos en Chile** — el universo observado, con su ficha por caso.
- **Los tribunales ambientales** — cómo opera la judicatura ambiental y qué llega efectivamente a ella.
- **Los datos, abiertos** — tablas descargables, metodología y fuentes.

Incluye además una sección de preguntas frecuentes, un glosario y el detalle de las fuentes utilizadas.

## Metodología

La sección de metodología describe el protocolo vigente de construcción del universo de casos y de codificación de cada conflicto. Los datos se publican junto con el sitio para que cualquiera pueda replicar los conteos.

## Contexto

La plataforma forma parte del programa de investigación sobre conflictos socioecológicos de SODAS (Universidad de Chile) y el Centro de Estudios Públicos.

## Cómo funciona

El sitio es un HTML autocontenido que se publica por GitHub Pages. Para verlo localmente basta abrir `index.html`.
